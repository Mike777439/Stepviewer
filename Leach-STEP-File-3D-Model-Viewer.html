    Getting the file out of SOLIDWORKS

    1. Open the part or assembly, then File → Save As.
    2. Set Save as type to STEP AP214 (*.step; *.stp).
    3. Open the file here. Assemblies keep their part tree, part names and colours.

    Native .SLDPRT / .SLDASM files use a closed format that browsers can't read, so save a STEP copy first. Nothing leaves your computer: files are read locally in the browser.

    In SOLIDWORKS

    1. Open the file and choose File → Save As.
    2. Set Save as type to STEP AP214 (*.step; *.stp) and save.
    3. Open the new .step file here.

    For assemblies, STEP keeps the part structure, names and colours. STL and VRML also work, but give a single mesh without part names.
